# TaskManager

TaskManager — учебное веб-приложение для планирования и управления личными задачами.

## Основные возможности

- Создание, редактирование и удаление задач.
- Управление статусами и приоритетами.
- Установка сроков выполнения.
- Фильтрация и сортировка задач.
- Сохранение данных с помощью localStorage.

## Технологии

- React
- TypeScript
- Vite
- JavaScript API localStorage

## Управление проектом

- Jira Software — планирование задач и спринтов.
- Confluence — документация проекта.
- GitHub — хранение исходного кода и контроль версий.

Проект разрабатывается в рамках дисциплины «Способы и системы управления программными проектами».
